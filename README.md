## 🎮 附加题完成情况（坦克大战）

- **开局规则确认**：进入游戏先展示完整规则说明（目标/耐久/血量/操作/敌军行为），
  玩家点击「我已了解，开始游戏」后才进入坦克选择；
- 开局可**自选坦克**：轻型·猎豹（高机动）/ 标准·战狼（均衡）/ 重型·堡垒（双倍伤害）；
- **横版宽屏** 960×600 画布（24×15 网格），5 个关卡：敌军数量、兵种
  （普通/快速/装甲）与地图障碍逐关递增；每关开始**生命重置为 3 条**、营地修复 +2；
- 敌军 AI 以**进攻我方营地**为目标：沿距离场寻路推进、炮轰挡路砖墙开路、
  与营地或玩家对齐时优先开火；
- **营地 7 发耐久**：营地最多承受 7 发炮弹（血条 + ❤ 实时显示），耐久归零即失败；
- 玩家坦克移动（WASD / 方向键）、开炮（空格），支持移动端虚拟按键；
- **打击感**：屏幕震动、枪口火光、爆炸冲击环、命中白闪、击毁飘分、
  WebAudio 合成音效（开火/命中/爆炸/营地受击/胜负）；
- 【身份标识】地图中央砖墙摆成姓名缩写「YYH」，画布右上角含「杨豫豪 · YYH」水印；
- 【底图加分】游戏底图采用「浪尖儿大学生社区」学员手册素材（bg.jpg），
